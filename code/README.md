# Code

Experiment code, one subfolder per experiment/project, e.g.:

```
code/
├── thymio_swarm_fission_fusion_controller/
│   └── README.md
└── real_mapping_argos_controller/
    └── README.md
```

Each experiment's README should cover install, configuration, and how to run it:

```markdown
# <Experiment Name>

## Overview

## Requirements

## Installation

## Configuration

## Usage
```

## Naming convention

Suggested format: `YYYYMMDD_short_description`, for easy sorting and searching.

## AI-assisted coding

Using AI coding tools is encouraged, but review and test the generated code before committing it.
