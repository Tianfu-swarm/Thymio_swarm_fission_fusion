# CAD

Mechanical drawings, kept in two formats:

```
cad/
├── editable/   # Editable native CAD files (SolidWorks, Fusion360, etc.)
└── step/       # Exported .stp/.step files
```

## Naming convention

Suggested format: `YYYYMMDD_short_description`, for easy sorting and searching. Keep the same filename in `editable/` and `step/` for a given part (extension differs only).
