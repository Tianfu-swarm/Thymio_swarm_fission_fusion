# CAD

All 3D models, CAD parts, and mechanical assemblies for this project were designed using OnShape.

View CAD Models on OnShape : https://cad.onshape.com/documents/584648bea63d64a5ea2ca077/w/08f70b3ba7f2741773ce9627/e/ec6d5b2b96eca5e0c03389e5?renderMode=0&uiState=6a7436f2b3b213b5f8db5320

## Access & Editing Permissions

Viewing & Exporting: The link above provides view-only access. You can inspect the 3D models directly in your browser and export parts into standard formats (.STEP, .STL, .IGES) without needing edit permissions.

Edit Access: The workspace is locked for editing by default. If you need edit permissions to modify the design files, please request access directly from Tianfu.

## Main Components

* Powerbank Container: Houses the power bank securely and provides a top surface designed for mounting an AprilTag marker for visual tracking.

* Raspberry Pi Container: A dedicated enclosure designed specifically to protect and hold the Raspberry Pi.

* Lock Platform: The base adapter that secures the entire top shell assembly to the Thymio robot using integrated LEGO-compatible studs/connectors.

## Future Improvements

* Connecting Rod Tolerances: Fine-tune mechanical tolerances on the connecting rods between parts for a smoother fit during assembly.

* Material & Heat Optimization: Add cutout holes across the enclosures to reduce overall structural weight, decrease 3D printing time, and improve passive heat dissipation for internal electronics.
